# 📱 LoseLine в Telegram — полный гайд

Этот файл — пошаговая инструкция, как превратить папку `tugriki-casino`
в работающее Telegram Mini App (мини-приложение внутри бота).

> **Главное:** игра полностью статическая. Для самого простого варианта
> **не нужны Python, Node.js, Git, сервер и токен бота**. Достаточно выложить
> файлы на любой HTTPS-хостинг и привязать ссылку к боту через @BotFather.

---

## 0. Что должно получиться

1. Игра открывается по публичной ссылке `https://...`.
2. В Telegram есть бот, у которого внизу слева кнопка **🎮 Играть**.
3. По нажатию игра открывается на весь экран внутри Telegram.
4. Баланс, банк и бонус синхронизируются между устройствами: телефон и компьютер
   под одним Telegram-аккаунтом — это **один игровой аккаунт** (ключ — хеш Telegram ID).
5. Промокоды одноразовые **глобально**: код нельзя активировать повторно
   с другого устройства. Баны игроков тоже общие.
6. Киберспорт подтягивает матчи Dota 2 / CS2 через публичный API.
7. В меню есть раннер «Побег по крышам», авто-прокрутка слотов и **техасский
   холдем** с блайндами, четырьмя кругами торговли и туториалом.
8. Под аккаунтом **@gusisurkovuch** доступна админ-панель с банами и списком
   всех известных игроков (ID, `@username`, баланс, банк, статистика).
9. При первом входе показывается политика конфиденциальности: нужны галочки
   «18+» и «принимаю условия», иначе игра не запускается.

## 1. Что понадобится

- Аккаунт Telegram.
- Аккаунт на одном из бесплатных хостингов (GitHub, Netlify или Cloudflare).
- Папка `tugriki-casino` с файлами игры.
- 10–20 минут времени.

Не нужно:

- покупать домен (можно использовать бесплатный поддомен);
- устанавливать программы;
- платить за сервер;
- подключать платежи, Telegram Stars или реальные деньги.

## 2. Шаг 1. Выложить игру на HTTPS

Telegram открывает Mini App **только по HTTPS**. Ссылки `http://`, `file://`
и `http://localhost` внутри Telegram не работают (localhost — только для
проверки в обычном браузере).

Выбери **один** из вариантов ниже.

### Вариант A. GitHub Pages (бесплатно и навсегда)

Подходит, если хочешь просто загрузить файлы через сайт, без Git и командной
строки.

1. Зарегистрируйся на [github.com](https://github.com).
2. Нажми **New repository**.
3. Название, например `loseline`. Тип — **Public**. Нажми **Create repository**.
4. На странице пустого репозитория нажми **Add file → Upload files**.
5. Перетащи **содержимое** папки `tugriki-casino`:
   - `index.html`
   - папку `css`
   - папку `js`
   - при желании `README.md`, `BOT-GUIDE.md`, `start.bat`, `serve.ps1`

   ⚠️ Важно: `index.html` должен лежать **в корне репозитория**, а не внутри
   вложенной папки `tugriki-casino`. Иначе адрес будет с лишним путём.
6. Внизу нажми **Commit changes**.
7. Открой **Settings → Pages**.
8. В блоке **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
   - Нажми **Save**.
9. Подожди 1–3 минуты. Вверху страницы Pages появится ссылка вида:
   `https://ТВОЙ_НИК.github.io/loseline/`
10. Открой её в браузере и проверь, что игра загрузилась.

Если сайт не появился сразу — обнови страницу через минуту. GitHub Pages
иногда собирается с задержкой.

### Вариант B. Netlify Drop (самый быстрый)

1. Открой [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащи **папку** `tugriki-casino` целиком в окно браузера.
3. Через несколько секунд получишь ссылку вида
   `https://random-name.netlify.app`.
4. Проверь игру по этой ссылке.

Плюс: ничего регистрировать не обязательно. Минус: при обновлении файлов нужно
заново перетащить папку (или зарегистрироваться и подключить Git).

### Вариант C. Cloudflare Pages

1. Зайди в [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages**.
2. **Create → Pages → Upload assets**.
3. Назови проект, например `loseline`.
4. Загрузи содержимое папки `tugriki-casino` (снова: `index.html` в корне).
5. **Deploy**. Получишь ссылку `https://loseline.pages.dev`.

### Вариант D. Свой хостинг / VPS

Подойдёт любой статический хостинг с HTTPS: nginx, Apache, Vercel и т.п.
Сертификат должен быть **валидным** (Let's Encrypt подходит). Самоподписанный
сертификат Telegram не примет.

## 4. Шаг 3. Создать бота в @BotFather (без кода)

1. Открой в Telegram **@BotFather**.
2. Отправь `/newbot`.
3. Введи **имя** бота, например `LoseLine`.
4. Введи **username**, он должен заканчиваться на `bot`,
   например `loseline_play_bot`.
5. BotFather пришлёт **токен** вида
   `123456789:AA...`.

   ⚠️ Токен — это пароль от бота. Не публикуй его и не выкладывай в GitHub.
   Если случайно засветил — отправь BotFather `/revoke`.

6. Оформи бота (необязательно):
   - `/setdescription` — текст на экране «Что умеет этот бот».
   - `/setabouttext` — короткое описание в профиле.
   - `/setuserpic` — аватар.
   - `/setcommands` — список команд. Например:

     ```text
     start - Открыть LoseLine
     play - Играть
     ```

### 4.1. Кнопка меню — самый простой способ

Это основной вариант: код не нужен, сервер не нужен.

1. В @BotFather отправь `/setmenubutton`.
2. Выбери своего бота.
3. Пришли ссылку на игру: `https://ТВОЙ_САЙТ/`.
4. Придумай название кнопки, например `🎮 Играть`.

Готово. Открой своего бота в Telegram: внизу слева появится кнопка меню.
Она открывает LoseLine на весь экран.

> Кнопка меню работает в **личном чате** с ботом. В группах и каналах её нет.

### 4.2. Красивая короткая ссылка (необязательно)

## 5. Шаг 4 (необязательно). Бот, который отвечает на `/start`

Кнопки меню достаточно для игры. Но если хочешь, чтобы бот отвечал на
`/start` сообщением с кнопкой «Играть», понадобится маленький сервер.

Ниже — самый простой бесплатный вариант: **Cloudflare Worker**.
Ни Python, ни Node.js, ни Git устанавливать не нужно — всё делается в браузере.

### 5.1. Создать Worker

1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. Открой **Workers & Pages → Create → Worker**.
3. Назови, например `loseline-bot`, нажми **Deploy**.
4. Нажми **Edit code** и замени весь код на этот:

```js
export default {
  async fetch(request, env) {
    // Telegram присылает секрет в заголовке — проверяем, что запрос от него
    const secret = request.headers.get('X-Telegram-Bot-Api-Secret-Token');
    if (request.method !== 'POST' || secret !== env.WEBHOOK_SECRET) {
      return new Response('LoseLine Mini App', { status: 200 });
    }

    let update;
    try {
      update = await request.json();
    } catch (e) {
      return new Response('ok');
    }

    const msg = update.message;
    if (!msg) return new Response('ok');

    const text = String(msg.text || '').trim();
    if (text.startsWith('/start') || text.startsWith('/play')) {
      const appUrl = env.WEBAPP_URL;

      await fetch(`https://api.telegram.org/bot${env.BOT_TOKEN}/sendMessage`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          chat_id: msg.chat.id,
          text:
            '🎮 LoseLine — игры и аркады на виртуальные тугрики.\n\n' +
            'Никаких реальных денег, Telegram Stars и платежей. ' +
            'Только игры, банк и промокоды. 18+.\n\n' +
            'Нажми кнопку ниже, чтобы играть.',
          reply_markup: {
            inline_keyboard: [[
              { text: '🎮 Играть', web_app: { url: appUrl } }
            ]]
          }
        })
      });
    }

    return new Response('ok');
  }
};
```

5. Нажми **Deploy**.

### 5.2. Добавить переменные

В настройках Worker открой **Settings → Variables and Secrets** и добавь:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен из @BotFather |
| `WEBHOOK_SECRET` | Secret | любая длинная случайная строка, например `loseline_8f3k2m9q` |
| `WEBAPP_URL` | Text | `https://ТВОЙ_САЙТ/` |

После добавления нажми **Save and deploy**.

### 5.3. Подключить webhook

Открой в браузере ссылку (подставь свои значения):

```text
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://loseline-bot.ТВОЙ_ПОДДОМЕН.workers.dev/&secret_token=<WEBHOOK_SECRET>&drop_pending_updates=true
```

Должно прийти:

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

Проверить состояние:

```text
https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
```

Если видишь `"last_error_message"` — читай ошибку: чаще всего это неверный
URL, HTTP вместо HTTPS или не совпал секрет.

### 5.4. Проверить

1. Открой бота в Telegram.
2. Отправь `/start`.
3. Должно прийти сообщение с кнопкой **🎮 Играть**.
4. Нажми кнопку — откроется LoseLine.

> Inline-кнопки `web_app` работают только в **личных чатах**. В группах
> Telegram их не покажет.

### 5.5. Если позже появится Node.js

Можно поднять такой же webhook на Node.js 18+ и любом хостинге с HTTPS
(Railway, Render, VPS). Логика та же: проверить заголовок
`X-Telegram-Bot-Api-Secret-Token`, разобрать JSON, отправить `sendMessage`
с `reply_markup.inline_keyboard[].web_app`. Главное — публичный HTTPS-адрес.

## 7. Как обновлять игру

1. Измени файлы в папке `tugriki-casino`.
2. Загрузи изменённые файлы на хостинг:
   - GitHub: **Add file → Upload files** → Commit.

3. Подожди сборку (GitHub Pages — до нескольких минут).
4. В Telegram закрой игру и открой заново.

Telegram и браузеры любят кэшировать. Параметр `?v=...` помогает сбросить кэш.

## 8. Банк, промокоды, аккаунт и баны: что важно знать

- **Банк** — это отдельное хранилище внутри игры. Тугрики из банка нельзя
  проиграть, пока не снимешь их обратно на баланс. Баланс, банк и кулдаун бонуса
  синхронизируются между устройствами одного Telegram-аккаунта через TextDB
  (ключ `loseline-wallet-v2-h-<sha256>`, синхронизация — в `js/app.js`).
- **Промокоды** — 60 кодов по 30 000 000 тугриков. Вводятся на экране
  «🎟️ Промокод» в главном меню.
- Код срабатывает **один раз на всех**: перед начислением приложение читает
  облако, проверяет claim, записывает его и делает контрольное чтение. Повторная
  активация отклоняется, даже если очистить данные браузера или зайти с другого
  устройства. Без интернета промокод не выдаётся.
- Коды лежат в `js/promo.js` и видны любому, кто откроет исходники сайта.
  Для игры с друзьями это нормально. Глобальные claims, кошельки, баны и список
  игроков хранятся в публичном `textdb.online`; настройки — в `js/cloud.js`.
  Ключи строятся от SHA-256 хеша (`h:`, `hu:`, `dv:`), а ID, `@username` и
  причины банов лежат в обфусцированных служебных полях. Это псевдонимизация,
  а не абсолютная защита: TextDB публичный, код открыт.
- В Telegram аккаунт определяется в первую очередь по **числовому Telegram ID**,
  а `@username` — запасной ключ. Поэтому телефон и компьютер с одним
  Telegram-аккаунтом видят один баланс и банк, даже если `@username` изменился.
- Синхронизация кошелька — по последней записи (`updatedAt`), с задержкой и
  троттлингом ради лимита TextDB. Если играть одновременно на двух устройствах,
  победит то, которое записало позже. Это не мгновенная серверная синхронизация.
- **Админ-панель**: под аккаунтом **@gusisurkovuch** в главном меню появляется
  кнопка «🛡️ Админ-панель». Там можно забанить игрока по `@username` или
  Telegram ID, указать причину, посмотреть список и разбанить. Если ID игрока уже
  известен, бан по username автоматически переносится на хеш ID.
- В админке есть блок **«Игроки · ID и статистика»**: ID, `@username`, баланс,
  банк, сумма и время последней синхронизации. Кнопка «В поле бана» подставляет
  ID в форму. Открытые ID и username admin видит только в этой панели.
- При бане игрок видит полноэкранный оверлей, а авто-прокрутка останавливается.
  Бан проверяется при старте, возврате во вкладку, фокусе, смене экрана и раз
  в 90 секунд.
- Очистка данных Telegram/браузера сбрасывает локальную копию, но кошелёк
  подтянется из облака при следующем входе; глобальный claim промокода и бан
  при этом не снимаются.
- **Удаление данных:** напиши @gusisurkovuch, укажи Telegram ID или `@username`.
  Облачный кошелёк, запись аккаунта, промокоды и бан будут удалены в разумный
  срок (до 30 дней), если нет законных оснований хранить их дальше.
- **Тугрики не имеют денежной ценности.** Их нельзя продавать, покупать,
  передавать, обменивать на деньги или услуги. Нарушение ведёт к бану.
- Это best-effort защита, а не серверная гарантия: TextDB публичный, запись
  неатомарная, а клиентский код можно обойти через инструменты разработчика.
  Для серьёзной защиты нужен собственный сервер с проверкой Telegram `initData`.

## 9. Проблемы и решения

| Проблема | Причина и решение |
|---|---|
| BotFather пишет, что URL должен быть HTTPS | Используй `https://`, а не `http://` или `file://`. Для теста локально — только обычный браузер. |
| Кнопка меню не появилась | Проверь, что `/setmenubutton` применён к нужному боту. Открой личный чат, перезапусти Telegram. Обнови клиент. |
| Внутри Telegram белый экран | Не загрузились `css`/`js`. Проверь ссылки в браузере, убедись, что `index.html` лежит в корне, а пути относительные. |
| 404 на `style.css` или `app.js` | При загрузке получилась вложенная папка. Нужно, чтобы рядом с `index.html` были папки `css` и `js`. |

## 10. Ограничения и безопасность

- Это **игры и аркады на виртуальные тугрики**: тугрики нельзя купить,
  продать, вывести, передать или обменять. Реальных денег, Telegram Stars,
  платежей и призов нет. 18+.
- **Приватность — псевдонимизация, а не анонимность.** В TextDB ключи строятся
  от SHA-256 хеша с солью, а ID, `@username` и причины банов обфусцированы.
  Но хранилище публичное, соль есть в коде, а клиентскую логику можно изучить.
  Не используй игру для чувствительных данных. Удаление — через @gusisurkovuch.
- Баланс, банк и рекорды синхронизируются между устройствами одного Telegram-аккаунта,
  но технически их можно изменить через инструменты разработчика — это игра для
  друзей, а не турнир на призы.
- Использованные промокоды, кошельки, баны и список игроков лежат в публичном
  `textdb.online`. Синхронизация идёт по последней записи и с задержкой, запись
  неатомарная, сервис публичный, а клиентский код можно обойти. Абсолютной
  гарантии без сервера нет.
- Промокоды находятся в клиентском коде, поэтому не являются секретом.
- Админ-панель определяет доступ по `initDataUnsafe.user.username` и не проверяет
  подпись Telegram на сервере. Для игры с друзьями этого достаточно, но против
  подмены клиента — нет.
- Киберспорт зависит от публичного API `bo3.gg` и прокси — возможны задержки
  и временная недоступность.
- Если когда-нибудь захочешь серверную экономику и честные промокоды:
  1. Перенеси баланс в базу данных.
  2. Проверяй `initData` от Telegram (подпись HMAC-SHA256 с токеном бота).
  3. Выдавай промокод атомарно на сервере.
  4. Никогда не доверяй сумме, которую присылает клиент.

### Что такое проверка `initData` (кратко)

Telegram передаёт в Mini App строку `initData`. На сервере её проверяют так:

1. Берут `hash` из `initData`.
2. Сортируют остальные поля и склеивают в строку `key=value` через `\n`.
3. Считают `HMAC-SHA256` с ключом `HMAC-SHA256("WebAppData", BOT_TOKEN)`.
4. Сравнивают с `hash`.

Если подпись верна — данным можно доверять. В этой статической версии проверка
не используется, потому что сервера нет.
