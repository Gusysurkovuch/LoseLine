# 🎮 LoseLine — Telegram Mini App

Мини-приложение с играми и аркадами на **виртуальные тугрики**, ставками на киберспорт и бесконечным раннером:

- 🏺 **Пирамида удачи** — слоты 5×3, 20 линий, вайлд-пирамида, скарабей-скаттер и фриспины ×2 (RTP ≈ 93%); есть **авто-прокрутка**
- 🎡 **Рулетка** — европейская, 37 чисел: красное/чёрное, чёт/нечет, 1–18/19–36, зеро 35:1; в покое колесо слегка покачивается
- 🃏 **Блэкджек** — 6 колод, дилер стоит на 17, блэкджек платит 3:2, удвоение
- ♠️ **Техасский холдем** — хедз-ап против дилера: блайнды, 2 закрытые карты, флоп/тёрн/ривер, чек/колл/рейз/фолд/олл-ин; верхнего лимита ставки нет
- 🏃 **Побег по крышам** — раннер в духе Subway Surfers: 3 полосы, прыжок, подкат, монеты, препятствия и временные множители ×2 / ×3 / ×5 / ×10
- 🎮 **Киберспорт** — матчи Dota 2 и CS2: ставки на команды виртуальными тугриками и трансляции Twitch/YouTube
- 🔊 **Звук и музыка** — синтезированные эффекты и фоновая аркадная музыка (Web Audio, без аудиофайлов); кнопка 🔊/🔇 в шапке
- 🏦 **Банк** — тугрики можно перевести в банк: там они сохраняются и не тратятся на ставки, снять можно в любой момент
- 🎟️ **Промокоды** — 60 кодов по 30 000 000 тугриков; каждый код активируется **один раз на всех**
- 📄 **Условия и конфиденциальность** — экран согласия при первом входе: 18+ и принятие политики; без обеих галочек игра недоступна
- 🛡️ **Админ-панель** — администратор **@gusisurkovuch** может банить и разбанивать игроков по `@username` или Telegram ID, а также видит список всех известных игроков с ID, `@username`, балансом, банком и временем синхронизации
- 🔗 **Один аккаунт на всех устройствах** — игровой профиль привязан к числовому Telegram ID: баланс, банк и кулдаун бонуса общие на телефоне и компьютере
- ♾️ **Без лимита ставки** — сумму можно ввести вручную в любой игре (слоты, рулетка, блэкджек, холдем, киберспорт); плюс/минус, быстрые суммы и MAX тоже работают
- 🎁 **Бонус** — раз в 5 часов, случайная сумма от 1 000 000 до 100 000 000 тугриков

Никаких реальных денег, никаких Telegram Stars, никаких платежей. Баланс, банк
и время бонуса синхронизируются между устройствами одного Telegram-аккаунта через
публичный `textdb.online` (с троттлингом), а промокоды, баны и список игроков
хранятся там же глобально. Ключи аккаунтов строятся от **SHA-256 хеша** Telegram ID,
а `@username`, ID и причины банов не публикуются открытым текстом. Это
псевдонимизация и обфускация, а не абсолютная защита — подробности в разделе
«Приватность». Без сети игра работает на локальной копии, а изменения отправятся
при следующем подключении.

## ▶️ Быстрый запуск на компьютере

1. Дважды кликни **`start.bat`** (или в PowerShell выполни
   `powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080`).
2. Откроется `http://localhost:8080/` — можно играть прямо в браузере.

> Скрипт `serve.ps1` — крошечный локальный веб-сервер на PowerShell.
> Python и Node.js не нужны.

## 📱 Как открыть это отдельным окном в Telegram

Telegram Mini App открывается **только по HTTPS-ссылке**, поэтому файлы нужно
куда-то выложить. Бесплатные варианты:

> 📖 Подробный гайд со всеми шагами, BotFather, кнопкой меню и необязательным
> сервером для `/start` — в файле **[BOT-GUIDE.md](BOT-GUIDE.md)**.

### Вариант A. GitHub Pages (бесплатно и навсегда)

1. Зарегистрируйся на github.com.
2. Создай новый репозиторий, например `tugriki` (Public).
3. Загрузи в него **всё содержимое этой папки** (`index.html`, папки `css`, `js`).
4. Открой репозиторий → **Settings** → **Pages**.
5. В разделе *Build and deployment*: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/ (root)** → **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ТВОЙ_НИК.github.io/tugriki/`

### Вариант B. Netlify Drop (без Git)

1. Открой `app.netlify.com/drop`.
2. Перетащи папку `tugriki-casino` в окно.
3. Получишь HTTPS-ссылку вида `https://random-name.netlify.app`.

### Вариант C. Свой хостинг / VPS

Любой статический хостинг с HTTPS подойдёт: Cloudflare Pages, Vercel,
обычный nginx с сертификатом.

## 🤖 Создание бота в Telegram (без кода!)

Код бота не нужен — мини-приложение вешается на **кнопку меню**.

1. Открой **@BotFather** → `/newbot`.
2. Придумай имя и username (username должен заканчиваться на `bot`).
3. (Необязательно) `/setdescription`, `/setuserpic` — оформи бота.
4. Выложи мини-апп на HTTPS (см. выше) и скопируй ссылку.
5. В @BotFather: **`/setmenubutton`** → выбери своего бота → пришли ссылку →
   придумай название кнопки, например `🎰 Играть`.
6. Открой своего бота → внизу слева появится кнопка меню — она открывает
   игру на весь экран (это и есть «отдельное окно»).

> Токен бота тут не нужен вообще: нет серверной части, нет платежей.

## ⚙️ Настройки

Открой `js/app.js`, блок `CONFIG` в самом верху:

```js
const CONFIG = {
  startBalance: 10000,   // стартовый баланс
  minBet: 10,            // минимальная ставка
  maxBet: Infinity,      // верхнего лимита нет — можно ставить весь баланс
  betStep: 10,           // шаг изменения ставки
  bonusMin: 1000000,     // минимальный бонус
  bonusMax: 100000000,   // максимальный бонус
  bonusCooldownMs: 5 * 60 * 60 * 1000, // бонус раз в 5 часов
  storageKey: 'tugriki_casino_v1',
  walletSyncDelayMs: 15000,   // задержка перед отправкой кошелька
  walletMinWriteMs: 180000,   // не чаще одной записи в 3 минуты
  walletForceWriteMs: 20000,  // ускоренная запись при уходе с экрана
  walletCheckMs: 25000,       // как часто проверять облако
};
```

Кошелёк (баланс + банк + бонус) хранится в отдельной записи TextDB
`loseline-wallet-v2-h-<sha256>`: ключ — первые 32 символа SHA-256 от ID с солью,
а не открытый Telegram ID. При синхронизации побеждает более свежая запись;
запись в облако троттлится, чтобы не исчерпать лимит бесплатного сервиса.
Ключ строится в `js/cloud.js` (`walletKey`, `walletKeyFor`), а синхронизация —
в `js/app.js` (`syncWallet`, `initWalletSync`). Старые ключи
`loseline-wallet-v1-id-*` и `v1-u-*` читаются только для мягкой миграции.

Слоты (символы, веса, выплаты, линии) — в `js/slots.js`, объект `SYMBOLS`
и массив `LINES`; там же логика авто-прокрутки. Звуки и музыка — в `js/sound.js`
(частоты, темп, громкость). Киберспорт — `js/esports.js`
(игры, кэш, ставки). Промокоды — массив `CODES` в начале `js/promo.js`
(сумма — константа `REWARD`). Общий ключ TextDB, имя администратора и проверка
банов — в начале `js/cloud.js` (имя администратора также продублировано в
`js/admin.js`). Параметры раннера (скорость, цена монеты, длительность
множителей) — в начале `js/runner.js`.

- Звук включается/выключается кнопкой **🔊** в правом верхнем углу. Состояние

  карты, колесо рулетки, выигрыши и проигрыши. Внешних mp3/wav нет.
- Фоновая музыка в стиле аркадных мобильных игр — простой луп (бас, арпеджио,
  ударные) на тех же синтезаторах. Запускается после первого касания/клика
  (требование браузеров) и выключается вместе со звуком кнопкой 🔊.

## 🏦 Банк, 🎟️ промокоды и глобальные проверки

- **Банк** — отдельный экран из главного меню. Введи сумму и нажми «Положить»:
  тугрики уходят с баланса в банк и **не участвуют в ставках**. Кнопка «Снять»
  возвращает их на баланс, «Всё в банк» / «Забрать всё» переводят всю сумму.
  Банк сохраняется в том же `localStorage`, что и баланс, и переживает перезапуск.
- **Промокоды** — отдельный экран. Всего 60 кодов, каждый даёт
  **30 000 000 тугриков**. Код считается использованным **глобально**: перед
  начислением приложение читает облако, проверяет код, записывает claim и делает
  контрольное чтение. Повторно активировать его нельзя ни на этом, ни на другом
  устройстве. Без сети промокод **не выдаётся**.
- На экране промокодов есть два счётчика: «Ты активировал» — локальная история,
  «Активировано всего» — данные из облака. Локальный список нужен только для
  удобства; решает глобальная проверка.
- Использованные промокоды, баны, список игроков и привязка аккаунта хранятся
  в публичном **`textdb.online`** (ключ `loseline-cloud-v2-msztw3jixe85`,
  настройки — в `js/cloud.js`). Промокоды находятся в `js/promo.js`
  (массив `CODES`). Записи используют псевдонимные ключи (`h:<hash>` для ID,
  `hu:<hash>` для username) и обфусцированные служебные поля вместо открытых
  ID и `@username`.
- В Telegram игровой аккаунт привязан в первую очередь к **числовому Telegram ID**,
  а `@username` используется как запасной ключ. Поэтому телефон и компьютер с
  одним Telegram-аккаунтом — это **один игровой аккаунт**, даже если `@username`
  изменился.
- **Баланс, банк и кулдаун бонуса** синхронизируются через отдельную запись
  `loseline-wallet-v2-h-<sha256>`: при открытии игра читает облако и забирает
  более свежие данные, а изменения отправляет с задержкой (обычно раз в 3 минуты,
  при уходе с экрана — быстрее). Так на телефоне и компьютере один и тот же
  баланс и банк. Последняя запись побеждает по времени `updatedAt`. На сайте без
  Telegram используется отдельный ключ `loseline-wallet-v2-d-<hash устройства>` —
  он привязан только к этому браузеру.
- Очистка данных браузера/Telegram сбрасывает локальную копию, но при следующем
  входе кошелёк подтянется из облака. Глобальный claim промокода и бан при этом
  **не** снимаются. Для удаления облачных данных напиши администратору
  **@gusisurkovuch** — порядок описан в разделе «Приватность».
- Это best-effort защита для игры с друзьями: TextDB публичный, запись
  неатомарная, а клиентский код можно обойти через инструменты разработчика.
  Абсолютная гарантия «один код на всех» и честный кошелёк возможны только на
  собственном сервере с проверкой Telegram `initData`.

## 🏃 Раннер и ♾️ авто-прокрутка

- **«Побег по крышам»** — бесконечный раннер с псевдо-3D на Canvas 2D.
  Три полосы, прыжок, подкат, монеты и препятствия: низкий барьер нужно
  перепрыгнуть, под перекладиной — подкатиться, блок/поезд — обойти по другой
  полосе. Вся графика нарисована с нуля, ничего не копируется из Subway Surfers.
- Управление: на телефоне — свайпы прямо по игровому полю (влево/вправо —
  смена полосы, вверх — прыжок, вниз — подкат), экранные стрелки на телефоне
  скрыты. На компьютере остаются кнопки ◀ ⬆ ⬇ ▶ под полем, мышь и клавиатура
  (`←`/`→`, `↑`/`W`/пробел, `↓`/`S`, `Esc`/`P` — пауза).
- **Множители** ×2 / ×3 / ×5 / ×10 выпадают как бонусы и действуют 12 секунд.
  Новый бонус не уменьшает множитель: берётся максимум, а таймер обновляется.
  Цена монеты — 500 тугриков × текущий множитель.
- Монеты начисляются на баланс пакетами (каждые 1.5 секунды, при паузе,
  завершении забега, уходе с экрана и закрытии страницы), поэтому прогресс
  не теряется. Рекорд дистанции хранится локально.
- При уходе с экрана, сворачивании Telegram или открытии другого экрана забег
  автоматически ставится на паузу.
- **Авто-прокрутка слотов** — кнопка под барабанами. Сама останавливается,
  если не хватает баланса, при уходе с экрана слотов, скрытии вкладки, бане или
  повторном нажатии. Один спин всегда завершается перед следующим.

## ♠️ Техасский холдем

- Отдельный экран из главного меню: **хедз-ап техасский холдем** против дилера.
  Ты ставишь **большой блайнд** (сумма из поля ставки), дилер — малый блайнд.
  Верхнего лимита нет: рейз ограничен только твоим балансом.
- Каждому раздаются **2 закрытые карты**, на стол выкладываются **5 общих**:
  флоп (3), тёрн (1), ривер (1). Всего четыре круга торговли.
- Действия: **чек**, **колл**, **рейз** (поле «рейз до»), **фолд**, **олл-ин**.
  На префлопе первым действует дилер, после флопа — ты.
- Собери лучшую **пятёрку из 7 карт** (2 своих + 5 общих). Комбинации:
  стрит-флеш → каре → фулл-хаус → флеш → стрит → сет → две пары → пара →
  старшая карта. При равенстве банк делится.
- Дилерский стек виртуально равен твоему стартовому балансу, поэтому дилер
  всегда может уравнять ставку, а сайд-потов не бывает.
- Дилер играет по простой стратегии: иногда блефует, иногда сбрасывает.
- Кнопка **«📖 Как играть»** открывает туториал с блайндами, улицами,
  кругами торговли и порядком комбинаций.
- Все ставки — только виртуальные тугрики. Реальных денег и призов нет.

## 🛡️ Админ-панель и баны

- Под Telegram-аккаунтом **@gusisurkovuch** в главном меню появляется кнопка
  «🛡️ Админ-панель». Внутри можно забанить игрока по `@username` или числовому
  Telegram ID, указать причину, посмотреть список банов и разбанить.
- В админке есть блок **«Игроки · ID и статистика»**: для всех известных игроков
  показываются Telegram ID, `@username`, баланс, банк, сумма и время последней
  синхронизации кошелька, а также статус бана. Кнопка «В поле бана» подставляет
  ID игрока в форму. Список читается из облака и обновляется кнопкой «↻».
  В облаке ID и `@username` хранятся псевдонимно, а в этой панели админ видит
  их расшифровку.
- Запись о бане хранится в облаке. Приложение проверяет её при старте, возврате
  во вкладку, фокусе окна, смене экрана и раз в 90 секунд. Если аккаунт забанен,
  показывается полноэкранный оверлей с причиной, а авто-прокрутка останавливается.
- Если бан выдан по `@username`, а Telegram ID этого игрока уже известен, бан
  автоматически **переносится на хеш ID** (`h:<hash>`) и продолжает действовать
  после смены username. Бан по числовому ID срабатывает всегда — для этого не
  нужен `@username`.
- Разбан принимает и `@username`, и ID: приложение проверяет все связанные ключи
  (`h:`, `hu:`, `dv:` и старые записи) и снимает найденные совпадения.
- Доступ администратора определяется по `initDataUnsafe.user.username` из
  Telegram и **не проверяется подписью на сервере**. Это удобно для игры с
  друзьями, но не является защитой от подмены клиента.

## 🎮 Киберспорт

- Отдельный экран с матчами **Dota 2** и **CS2**: турнир, команды, время, формат
  (BO1/BO3/BO5), звёзды популярности и коэффициенты.
- Ставка — только **виртуальные тугрики**. Выбери команду, сумму (или `MAX`)
  и нажми «Поставить». Выигрыш = сумма × коэффициент, при отмене матча ставка
  возвращается. На один матч — одна открытая ставка.
- Результаты подтягиваются по кнопке «Проверить результаты» и автоматически при
  открытии экрана (не чаще раза в 2 минуты). Пока матч не завершён, ставка
  остаётся открытой.
- Трансляции: кнопка «▶ Смотреть» открывает официальный стрим матча
  (Twitch/YouTube), если он есть у турнира. Если встроенный плеер недоступен,
  остаются ссылки «Открыть трансляцию» и «Матч на bo3.gg».
- Данные — публичный API **`api.bo3.gg`**. У него нет CORS-заголовков, поэтому
  запросы идут через текстовый прокси **`r.jina.ai`** (запасной —
  `api.allorigins.win`). Это может работать медленнее, чем обычный API, и
  зависеть от доступности прокси.
- Если у матча нет реальных коэффициентов, используется виртуальный коэффициент
  **×1.90** — об этом честно написано на карточке и в окне ставки.

## ⚠️ Ограничения и честные предупреждения

- **Баланс и банк синхронизируются между устройствами одного Telegram-аккаунта**
  через TextDB по последней записи (`updatedAt`). Это не мгновенная синхронизация:
  изменения отправляются с задержкой и могут разойтись, если играть одновременно
  на двух устройствах. Побеждает тот, кто записал позже. Для игры с друзьями этого
  достаточно; для турниров нужен сервер.
- **Приватность — псевдонимизация, а не анонимность.** Ключи в TextDB строятся
  от SHA-256 хеша с солью, а служебные поля обфусцированы. Но это публичное
  хранилище и открытый клиентский код: при достаточном желании данные можно
  сопоставить. Не используй игру для чувствительной информации.
- **Глобальные данные** (кошельки, использованные промокоды, баны, список игроков)
  работают через бесплатный публичный `textdb.online`. Это best-effort защита,
  а не серверная гарантия: TextDB публичный, запись неатомарная, клиентский код
  можно обойти через инструменты разработчика. Для серьёзных призов нужен
  собственный сервер с проверкой Telegram `initData`.
- Бан и админка тоже клиентские: приложение проверяет бан при старте, фокусе,
  смене экрана и раз в 90 секунд, но технически защиту можно обойти. Бан по
  числовому Telegram ID надёжнее бана по `@username`; при известном ID бан по
  username автоматически переносится на хеш ID.
- Киберспорт зависит от чужого публичного API и прокси: список матчей может
  обновиться с задержкой, а коэффициенты и трансляции — отсутствовать у
  небольших турниров. Ставки всё равно остаются виртуальными.
- Это **не** азартная игра на деньги: тугрики нельзя купить, продать, вывести
  или обменять. Платежи и Telegram Stars не используются. Тугрики не имеют
  денежной ценности, их нельзя передавать — нарушение ведёт к бану.
- 18+. Если игра перестаёт быть развлечением — сделай перерыв.
- «Пирамида удачи» — **собственная** тема и своя математика (RTP ≈ 93%).
  Графика и таблицы выплат сторонних автоматов не копируются.

## 🔧 Если что-то не работает

| Проблема | Решение |
|---|---|
| `http://localhost:8080` не открывается | Порт занят — запусти `.\serve.ps1 -Port 8090` |
| Telegram не открывает кнопку | Ссылка должна быть **https**, не `http` и не `file://` |
| Пустой экран в Telegram | Проверь, что `css/` и `js/` загрузились на хостинг (пути относительные) |
| Баланс не сохраняется | В Telegram WebView может быть запрещён `localStorage` — проверь настройки приватности |
| На телефоне и ПК разный баланс | Кошелёк синхронизируется с задержкой (до ~3 минут). Закрой игру на одном устройстве, открой на другом и подожди пару секунд; проверь, что оба заходят в Telegram под **одним аккаунтом**. В админке видно время последней синхронизации |
| Промокод не срабатывает | Проверь код (регистр не важен). Код мог быть уже активирован **на любом устройстве**, либо нет связи с `textdb.online` — без сети промокод не выдаётся |
| Код принят, но баланс не изменился | Обнови страницу и проверь «Активировано всего»; если код есть в облаке, а баланс не начислен — напиши администратору |
| Не появилась админ-панель | Она видна только в Telegram под аккаунтом **@gusisurkovuch**. На `localhost` для отладки можно временно выставить `window.LOSELINE_DEV_USER` (на опубликованном сайте эта подмена отключена) |
| В админке не видно игроков | Список берётся из облака: нажми «↻ Обновить». Игрок появляется после первого входа в игру под своим Telegram-аккаунтом |
| Показывается «Доступ заблокирован» | Аккаунт забанен администратором. Причина указана на оверлее; разбан — только через @gusisurkovuch |
| Бан по ID не действует | Открой админку, нажми «↻ Обновить» и введи **числовой** Telegram ID без `@`. Если бан был выдан по username до того, как стал известен ID, обнови список и забани заново по ID |
| Бан не снимается | Нет связи с `textdb.online` или указан неверный `@username`/ID. Разбан принимает и username, и ID — проверь облако и повтори |
| Монеты раннера не пришли | Они начисляются пакетами: подожди 1.5 секунды, заверши забег или выйди с экрана. Баланс должен обновиться |
| Авто-прокрутка выключилась | Закончился баланс, ты ушёл с экрана слотов, свернул вкладку или аккаунт забанен — это нормальная защита |
| Банк обнулился | Очищены данные браузера/Telegram — при следующем входе кошелёк подтянется из облака. Если и в облаке пусто, банк был не синхронизирован |
| В холдеме не нажимается «Раздать» | Проверь большой блайнд: минимум 10, максимум — баланс. Поле ставки скрывается во время раздачи |
| Холдем: непонятны действия | Нажми «📖 Как играть» — там блайнды, флоп/тёрн/ривер, круги торговли и комбинации |
| Не закрывается экран условий | Нужно поставить **обе** галочки: 18+ и согласие с политикой. Это обязательное условие входа |
| Хочу удалить свои данные | Напиши @gusisurkovuch и укажи Telegram ID или @username — облачный кошелёк, аккаунт, промокоды и бан будут удалены |
| Трансляция не открывается | Twitch/YouTube могут запрещать встраивание — используй ссылки «Открыть трансляцию» и «Матч на bo3.gg» |
